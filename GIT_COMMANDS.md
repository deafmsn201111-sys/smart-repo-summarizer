## Troubleshooting

### Authentication Issues

If you get authentication errors:

```bash
# Option 1: Use SSH (recommended)
git remote set-url origin git@github.com:YOUR_USERNAME/smart-repo-summarizer.git

# Option 2: Use Personal Access Token
git remote set-url origin https://YOUR_TOKEN@github.com/YOUR_USERNAME/smart-repo-summarizer.git
```

### Large Files

If you have large files to push:

```bash
# Install Git LFS
git lfs install

# Track large files
git lfs track "*.zip"
git lfs track "*.tar.gz"
```

### Force Push (Use Carefully)

```bash
# Only use if you need to rewrite history
git push --force-with-lease origin main
```
